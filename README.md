# EHS 법령 검토 도우미 2.0

제조공정과 건설·신축 현장의 제원에 맞는 법령 확인 항목, 필요한 증빙과 조치 기록을 정리하는 Streamlit 앱입니다.

## 실행

Windows에서는 `앱_실행.cmd`를 더블클릭합니다. 이미 실행 중이면 화면에 표시된 주소를 열면 됩니다. 실행환경은 현재 작업에서 검증한 별도 Python 환경을 우선 사용합니다.

다른 컴퓨터 또는 새 실행환경에서는 다음 순서로 설치합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## 사용하는 순서

1. 사업장 추가에서 실제 업종에 가까운 템플릿을 선택합니다. 15종 템플릿의 공정은 복수 선택·변경할 수 있습니다.
2. 인원·건축물·물질·설비·위험작업을 실제 자료에 맞게 입력합니다. 숫자를 모르면 빈칸, 여부를 모르면 미확인으로 둡니다.
3. 체크리스트에서 검토대상·추가확인 항목을 확인하고, 공식 근거·조건·필요 증빙을 검토한 뒤 담당자와 기한을 기록합니다.
4. 개정 영향성에 공식 개정 원문과 법적 상태를 입력합니다. 현행 법령·공포된 시행예정 개정·입법예고·국회 법률안을 구분합니다.
5. 원문에서 확인한 수치 조건은 직접 지정할 수 있습니다. 종전값·개정값·단위·시행일·근거 문구를 함께 기록합니다. 전체 사업장 비교도 지원합니다.
6. Excel 체크리스트와 전체 프로필 JSON을 저장합니다. 가상 시연 프로필은 `examples/demo_profiles.json`을 불러올 수 있습니다.

## 확장한 입력과 출력

- 15종 시작 템플릿: 클린룸, PCB, 프레스, 기계가공, 조립, 용접, 표면처리, 화학배합, 열처리, 식품, 배터리, 물류, 유틸리티, 공장 신축, 일반 건설·대수선.
- 31개 숫자 제원과 34개 여부 항목, 기본정보, 건물·물질·설비별 상세 명세.
- 공식 조문을 확인한 체크리스트 40개. 단일 면적·물질명으로 복합 대상성을 확정하지 않습니다.
- 개정 원문을 여러 주제로 나눠 원문 인용, 입력 근거, 누락 정보, 수치 비교, 시행 시점과 대응 확인사항을 제공합니다.
- 사업장 제원 변경 시 이전 완료·비대상 검토 기록을 재확인 대상으로 돌리고, 오래된 개정 분석 결과는 다시 분석하도록 처리합니다.
- Excel에는 제원·상세 명세·체크리스트·개정 검토 결과를 분리해 저장합니다.

## 저장·접근 방식

사업장 프로필과 검토 기록은 현재 브라우저 세션에 보관됩니다. 브라우저 연결 종료·서버 재시작 후에도 유지하려면 프로필 JSON을 저장하고 다시 불러옵니다. 공용 서버 파일이나 다른 사용자의 프로필 DB로 자동 저장하지 않습니다.

접근 코드가 필요하면 `EHS_ACCESS_CODE` 환경변수 또는 `.streamlit/secrets.toml`의 `access_code`를 설정합니다. 설정이 없을 때는 접근 코드 없이 열리는 시연 모드입니다. 기존 코드에 공개돼 있던 `1234`를 보안 인증이라고 표시하지 않습니다.

## 법령 판단 범위

규칙의 출처 확인일은 2026-10-12이며, 실시간 법령 수집·자동 최신화는 포함하지 않습니다. 모든 산업안전보건·건축·소방·환경 의무를 망라하거나 법적 준수를 인증하지 않습니다. 등록된 조건으로 관련성을 먼저 선별하고, 업종 적용 제외·별표·부칙·경과조치·지역 조례·개별 허가 조건은 추가 확인 대상으로 남깁니다. 건물별 명세와 전체 제원은 구분해 입력합니다.

물질명만으로 PSM·위험물·유해화학물질 분류를 확정하지 않습니다. 법안에 없는 점검주기·의무·시행일을 만들지 않고, 관련 단어가 없다는 이유로 영향 없음을 확정하지 않습니다. 출처별 시행 시점과 확인 한계는 `LEGAL_SOURCES.md`에 기록했습니다.

## 구성

- `app.py`: 화면·사업장 관리·파일 저장
- `profiles.py`: 제원·공정·템플릿과 입력 정규화
- `legal_catalogue.py`: 공식 출처 기반 체크리스트 규칙
- `core.py`: 미확인 값을 보존하는 조건 평가·Excel 출력
- `amendments.py`: 개정 원문 관련성·수치·시행 시점 분석
- `LEGAL_SOURCES.md`: 법령 출처와 확인한 범위
- `tests/`: 경계값·누락·개정안 상태·출력 검증

검증 명령:

```powershell
python -m unittest discover -s tests -v
```

프로토타입의 UI·조건 분기·자료 출력이 검증된 것이며, 개별 사업장의 법적 적용 여부가 검증되었다는 뜻은 아닙니다.
